# <img src="assets/app_icon.ico" width="45"/> LucidPathTool

**LucidPathTool** is a desktop utility designed to assist with local file searching. It helps you navigate directory structures to find specific files or duplicates, operating entirely offline.

### Why I made this?
Honestly, I got tired of manually digging through folders when I forgot where I saved a file. Or when I accidentally created duplicates in random places. Windows search can be slow or confusing, so I decided to build my own offline tool to solve this.

It helps you navigate complex folder structures and find what you need without the headache.

## How to Use

### 1. Search Tab (The main part)
Here is how you scan your files:

* **Folder Field:**
    Paste the path to the folder you want to check (e.g., `C:/Users/Name/Downloads` or just `D:/`).
    * *Note:* If you leave the "Name" field empty, it will just list **everything** in that folder.

    > **⚠️ IMPORTANT WARNING:**
    > Please **DO NOT** scan your entire system drive (like just `C:/`) without entering a specific file name. On older laptops or weak PCs, this will take a long time and might freeze the app for a bit because there are too many system files to list!

* **Name Field:**
    Type what you are looking for.
    * You can type a part of the name (e.g., `report` finds `Final_Report.docx`).
    * You can type just an extension (e.g., `.pdf` or `.exe`) to see all files of that type.

* **Launch:**
    Hit the **Search** button and wait for the results in the table.

### 2. Settings Tab
* I added **13 different themes**!
* If you don't like the default look, just pick another color scheme from the list.
